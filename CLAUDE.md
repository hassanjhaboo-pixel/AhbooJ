# Working rules for this repo

## Don't look vibecoded (applies to everything: Ahbooj OS screens, landing pages, motion graphics, decks, copy)
Hassan flagged these as tells that make work look AI-made. Avoid all of them unless a brand reason is written down:

1. Purple-to-blue gradients
2. Gradient hero text
3. Emojis in headings
4. Inter font everywhere
5. Coloured border cards
6. Glassmorphism cards
7. Low-contrast dark mode (small text must be ≥ 4.5:1)
8. Three icon boxes in a row
9. Badge/eyebrow above the headline
10. Lucide icons everywhere
11. Untouched shadcn UI
12. Fade-in on scroll (and rise/fade as the default entrance in videos)
13. Cursor-following beam
14. Buttons that only fade on hover
15. Inconsistent spacing (use one spacing scale)
16. Em dashes, in copy and in chat replies
17. Generic buzzword copy
18. Serif italic accent words
19. Space Grotesk + Instrument Serif
20. Grain over a gradient

Full table with what to do instead, for web and for video: `.claude/skills/brand-motion/references/anti-vibecode.md`.
Check new work against it before delivering. Existing Ahbooj OS screens still use some of these (Lucide icons,
backdrop blur); fix them when touching those files, not in unrelated changes.
