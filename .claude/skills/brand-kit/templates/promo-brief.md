# Promo brief — the 5-minute version

For recurring content: a weekly drop, a holiday box, a sale, a new flavour, an event. Copy, fill, and hand to brand-motion.

```
BRAND:        <slug>
PROMO:        <e.g. "Valentine's Sweet Box" / "This week's lineup" / "Grand-opening countdown">
OFFER:        <what, price, dates — exactly as it must appear; or "none, brand awareness">
ONE LINE:     <the hook, ≤ 6 words>
PROOF:        <products/photos to show: assets/products/*.png>
STYLE:        <pop-pulse | kinetic-type | line-journey | diorama-build | lineup-reveal | hero-constant | mockumentary | blend: A + B>
FORMATS:      <9:16 (default) · 1:1 · 4:5 · 16:9>
LENGTH:       <15s default · 30s · 45s+ for character/story spots>
VOICES:       <none · narrator line: "…" · characters: name — line — voice>
CTA:          <exact words + phone/url>
MUST AVOID:   <…>
SERIES:       <does it reuse a recurring character, set or opener? name it so the series stays consistent>
```

## Reuse checklist (keeps a series consistent)
- Same brand file, same signature transition, same end card layout.
- Recurring characters keep the same look options (torso, hair, colours) and the same voice id.
- Change the hook, the products and one gag per episode; keep the structure.
