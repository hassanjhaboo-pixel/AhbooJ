Use these in Midjourney, ChatGPT / DALL·E, Nano Banana (Gemini), Higgsfield, Ideogram or Leonardo. Attach `character-sheet.png`
(the v1.1 sheet I rendered) as a **reference image**, so the generator keeps the design rather than inventing a new alien.

**What I need back so I can rebuild him as an animated, layered character:**
- A **plain flat background** (pure white or flat #00FF00 green), so I can cut him out cleanly

- **Flat cel shading with thick, clean outlines** (sticker / vector style). Painterly or 3D renders can't be split into animatable layers

## Tool notes
- **Midjourney:** add `--ar 4:5 --style raw --stylize 100` and use the reference sheet as a character reference (`--cref <url>` or Omni Reference with weight 100). Then use `--sref` with your best result to keep the style consistent.
- **ChatGPT / Nano Banana / Higgsfield:** upload `character-sheet.png` and say *"keep this exact character design"* before the prompt. For edits, ask for one change at a time ("same image, now winking").
- **Ideogram:** good if you want "AREA 47" lettering on the hoodie. Elsewhere, leave text out; I add the brand text in the animation.
