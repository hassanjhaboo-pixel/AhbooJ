# Kafneo image prompts for Gemini AI Plus

With Plus you can make far more images a day, so we drop the gang sheets. **One asset per image** means every cup and close-up comes out at full resolution, which fixes the soft close-ups.

## How to run these in Gemini

1. **Pick the image model.** Pick the best image option in the model or tool menu (the "Pro" one if it's offered).
2. **One chat per numbered job.** Gemini keeps the same cup, light and set across a conversation. Do the follow-up prompts in that same chat, one message at a time.
3. **Attach the reference** where it says so. Do it in the first message of the chat only.
4. **Paste the STYLE BLOCK at the top of the first message** of each chat. Follow-ups don't need it.
5. **Say the aspect ratio in the prompt.** It's already written into each one below.
6. **Download with the download button** at full size. Don't screenshot.
7. **If something drifts** (a different cup shape, a new straw, extra ice), reply in the same chat: *"Keep everything identical to the previous image except [the one change]. Regenerate."*
8. **Name the files as listed** and send them to me as you finish each job.

## STYLE BLOCK (top of the first message in every chat)

> Premium commercial beverage photography for a specialty coffee shop. Photorealistic, full-frame camera, 85mm lens, one soft warm key light from the upper left, a gentle rim light from behind. Crisp, high detail, real condensation droplets. The cup is a clear 16 oz plastic iced-coffee cup with a flat clear lid and a straight paper straw, no logo, no label. No hands, no people, no text, no watermark. Maximum resolution.
